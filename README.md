Simple Web Page

Files:

- index.html — Main HTML file
- styles.css — Simple styles with light/dark theme
- script.js — Theme toggle and localStorage

How to open

- Double-click `index.html` to open in your default browser.
- Or run a quick local server (recommended):

```powershell
python -m http.server 8000
# then open http://localhost:8000/index.html
```
